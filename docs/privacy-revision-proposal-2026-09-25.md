## 2. 第9条の差し替え案（表の部分）

| サービス名 | 提供事業者 | 用途 | 取り扱われる情報 |
|---|---|---|---|
| Supabase | Supabase, Inc. | 本番データベース（PostgreSQL）。保存先は東京リージョン（ap-northeast-1） | 本サービスに登録された情報 |
| Replit | Replit, Inc. | アプリケーションの実行、ビルド、デプロイおよび稼働ログの記録 | 通信情報、アクセスログ、アプリケーションが処理する情報 |
| Netlify | Netlify, Inc. | 本ウェブサイト（LP・法務文書）の配信およびアクセスログ | 通信情報、アクセスログ |
| Cloudflare | Cloudflare, Inc. | ドメインの権威DNSの提供（通信内容の中継は行っていません） | ドメイン名の問い合わせに関する情報 |
| Formspree | Formspree, Inc. | 本ウェブサイトの登録フォームの受付 | フォームに入力された氏名、メールアドレス、所属等 |
| Google Fonts | Google LLC | ウェブフォントの配信 | 閲覧者のIPアドレス、ブラウザに関する情報 |
| Gmail | Google LLC | お問い合わせの受付および返信 | 氏名、メールアドレス、お問い合わせの内容 |

続く条文の案：

1. 当方は、本番データベースとして Supabase の東京リージョン（`ap-northeast-1`）を利用しています。
2. 当方は、アプリケーションの実行環境として Replit を利用しています。**Replit における処理の所在地は、同社の公開リージョンの設定によって決まります。現時点で当方は公開設定を行っておらず、所在地は確定していません。**（公開後に確定した内容へ差し替える）
3. 当方は、クレジットカード番号を保有しません。（※決済サービスを接続した時点で、提供事業者名とともに記載する）
4. 当方は、選手の傷害、コンディションおよび医療に関する情報を、外部の生成AIサービスその他の外部APIに送信しません。
5. 当方は、選手の傷害、コンディションおよび医療に関する情報を取り扱う画面において、広告配信またはアクセス解析を目的とした第三者提供のタグ等を設置しません。

## 3. 第10条（外国にある第三者への提供）の案

1. 前条に定める外部サービスの提供事業者は、いずれもアメリカ合衆国に所在する法人です。
2. **本番データベースに保存される情報は、Supabase の東京リージョンに保存されます。ただし、同社は日本国外に所在する法人であり、運用・保守のために国外からアクセスされる可能性があります。**
3. **アプリケーションの実行環境（Replit）における処理の所在地は、公開リージョンの設定によって決まります。現時点では未確定であり、日本国外で処理される可能性があります。**
4. 当方は、アメリカ合衆国における個人情報の保護に関する制度について必要な情報を把握した上で、委託先に対する必要かつ適切な監督を行い、安全管理措置を実施しています。
